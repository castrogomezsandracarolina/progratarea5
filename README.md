# Tarea 5 - Patrones de Diseño

**Curso:** Programación III  
**Integrantes:** Sandra Carolina Castro Gómez y Miguel Ángel Flores Cárdenas

## Archivos

- `ejercicio1_singleton.cpp`: transacciones bancarias con Singleton e hilos.
- `ejercicio2_abstract_factory.cpp`: motor de renderizado OpenGL y Vulkan.
- `ejercicio3_composite.cpp`: expresiones matemáticas y derivadas.

## Compilación

```bash
cmake -S . -B build
cmake --build build
```

Cada ejercicio tiene su propio `main()`.

**Ejercicio 1:** Con las operaciones del `main`, el saldo final es 1500. El enunciado indica 500.
